# Urbansketch — Interior Design Portfolio Website

A responsive portfolio website showcasing interior design projects, design services, and software skills.

## Overview

Urbansketch is an interior design portfolio website created to present design work, highlight project experience, and provide visitors with an overview of design services and tools.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Interior design portfolio presentation
- Software and skills section
- Responsive website layout
- Interactive website elements
- Custom branding and styling

## Project Structure

- `index.html` — Main website page
- `styles.css` — Website styling
- `script.js` — Interactive functionality
- `assets/` — Website images and other assets

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/maddirala-hari/urwebsite.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

## Project Purpose

This project demonstrates front-end website development and portfolio presentation for the Urbansketch interior design brand.
